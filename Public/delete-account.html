Delete your Heartmate AI data

This permanently deletes the Heartmate AI data associated with your signed-in account, including conversations, saved memories, relationship progress, companion profiles, photo records, voice preferences, notification preferences, daily welcomes and video-task records.

  1. Sign in to Heartmate AI using the Google account whose application data you want to delete.
  2. Open the chat page while signed in: Open Heartmate chat.
  3. In the same browser session, open your browser's developer console and run the request below. It uses your current Firebase sign-in token and requires an explicit confirmation string.
const user = window.heartmateUser;
if (!user) throw new Error("Please sign in first.");
const token = await user.getIdToken(true);
const response = await fetch("/api/account/delete", {
  method: "POST",
  headers: {
    "Content-Type": "application/json",
    "Authorization": "Bearer " + token
  },
  body: JSON.stringify({ confirm: "DELETE_MY_ACCOUNT" })
});
console.log(await response.json());

Important: this endpoint deletes Heartmate AI application records only. It does not delete your Google or Firebase Authentication identity. Remove that identity separately through the account provider. The deletion cannot be undone.
